## 2. Тип исследования

**Количественное** (одномоментное, сравнительное, корреляционное).

Обоснование: вопросы исследования звучат как «различается ли уровень выгорания» и «какие условия работы связаны с ним». Выгорание измеряется числом (сумма баллов по шкалам стандартного опросника), условия работы тоже сводятся к числам (часы, размер класса, баллы 1–5). Две существующие группы (государственные и частные школы) сравниваются статистически. Эксперимента нет: учителей нельзя случайно распределить по школам, поэтому выводы формулируются как связи, а не как причины. Качественная часть (интервью) не включена из-за малой выборки и сроков; это указано как ограничение.

## 3. Гипотезы

| Вопрос | H0 (нулевая) | H1 (альтернативная) |
|---|---|---|
| RQ1. Уровень выгорания | Уровень выгорания учителей государственных и частных школ не различается | Учителя государственных школ имеют более высокий уровень выгорания (выше эмоциональное истощение и деперсонализация, ниже достижения) |
| RQ2. Условия работы | Условия работы не связаны с выгоранием; разница между типами школ при их учёте не меняется | Чем выше требования (часы, размер класса, отчётность, давление родителей) и ниже ресурсы (поддержка, стабильность), тем выше выгорание; при учёте условий разница между типами школ уменьшается |
| RQ3. Различие причин (поисковый) | Сила связи каждого фактора с выгоранием не зависит от типа школы | В государственных школах сильнее связаны размер класса и отчётность (H3a, H3b), в частных — давление родителей и нестабильность работы (H3c, H3d) |

RQ3 носит поисковый характер: при 15–20 учителях в группе результаты описываются как тенденции.

## 5. Метрики и baseline

**Первичная метрика (Primary):** эмоциональное истощение (шкала опросника «Профессиональное выгорание», MBI в адаптации Водопьяновой и Старченковой). Главные показатели результата: разница между группами (d Коэна), сила связи условий работы с выгоранием (ρ Спирмена, β, ΔR²).

**Вторичные метрики:** деперсонализация, редукция профессиональных достижений, интегральный индекс выгорания.

**Пороговые метрики (Guardrail):**
- надёжность шкал: альфа Кронбаха не ниже 0,7;
- не менее 15 полных анкет в каждой группе;
- доля исключённых анкет (фиксируется и сообщается);
- сопоставимость групп по контрольным переменным.

**Формулы:**
- d = (M_гос − M_част) / SD_общ
- ΔR² = R²(шаг 2) − R²(шаг 1)
- α = k/(k−1) · (1 − Σσᵢ² / σ²_сумма)

**Baseline (точка сравнения):**
1. Референтная группа: учителя государственных школ (массовый тип), с ними сравниваются учителя частных школ.
2. Нормативный ориентир: средние значения авторов адаптации опросника (ЭИ 19,73; ДП 7,78; РПД 32,93). Используются только описательно, так как нормы получены на российских выборках.
3. Базовая модель: регрессия только с типом школы (шаг 1); с ней сравнивается модель с условиями работы (шаг 2).

**Анализ:** t-тест Уэлча (при ненормальности U-тест Манна–Уитни) для RQ1; корреляции Спирмена и иерархическая регрессия для RQ2; корреляции по группам для RQ3. Уровень значимости 0,05, критерии двусторонние. Инструменты: JASP (иерархическая регрессия, β, ΔR²); скрипт `src/benchmark.py` в репозитории воспроизводит остальное: баллы шкал, альфу Кронбаха, сравнение групп (t-тест Уэлча, U-тест, d Коэна) и корреляции Спирмена.

## 6. Основные угрозы валидности

| Угроза | Мера защиты |
|---|---|
| Нет случайного распределения по школам (внутренняя) | выводы только как связи; контроль стажа, классного руководства, ступени |
| Эффект отдельной школы | указано в ограничениях; название школы не собирается |
| Социальная желательность | анонимность; нейтральное название анкеты; прямой вопрос «есть ли у вас выгорание» не задаётся |
| Малая выборка (30–40) | эффекты и доверительные интервалы вместо одного p; RQ3 поисковый |
| Самоотбор респондентов, один город (внешняя) | описание выборки; результаты не переносятся на всю страну |
| Нормы только российские | уровни выгорания используются для описания, группы сравниваются по сырым баллам |
